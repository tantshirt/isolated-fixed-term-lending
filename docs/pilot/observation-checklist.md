# Observation checklist

Use it for every observed session after onboarding. Watch, do not help. If the participant asks a question, answer only "What would you expect?" and write it down.

For each session, record:

- Date, alias, desk id, and which flow they attempted.
- Whether the flow finished, and how long it took.
- Every hesitation longer than about ten seconds, and what was on screen.
- Every question they asked aloud.
- Every error message they saw, word for word.
- Any time they left ZenLo (to a wallet, explorer, chat or spreadsheet), and why.
- Whether you intervened. If you did, mark the resulting loan **assisted**, and write down what you did and why.

After the session:

- One line: what blocked them most.
- One line: what they did that we did not expect.
- File any defect touching custody, authorization or settlement as **critical**. The gate cannot pass while one is open.

Weekly, add up:

- Desks activated and loans confirmed per desk, excluding developer wallets.
- Assisted and unassisted originations.
- Lenders who came back for a second loan.
